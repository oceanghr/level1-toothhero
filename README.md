Level 1 — Tooth Explorer
C1 · Mengingat
Aktivitas: Anak menjelajahi kamar mandi dan mengetuk benda-benda yang digunakan untuk merawat gigi, seperti sikat gigi, pasta gigi, dan benang gigi. Saat disentuh, benda menampilkan nama serta fungsinya.
Tujuan: Anak mengenali dan mengingat alat serta informasi dasar kesehatan gigi.
Bentuk gameplay: Eksplorasi dan interaksi dengan objek, bukan kuis.
